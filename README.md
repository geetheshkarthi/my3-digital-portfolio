# MY3 Digital · Interactive 3D Portfolio

An interactive 3D portfolio and website showcase for **MY3 Digital**, built with Three.js, GSAP, and HTML5 WebGL.

## Features

- **3D Fibonacci Sphere Gallery**: Interactive spherical video gallery with mouse drag physics, inertial rotation, and smooth card zoom-in overview.
- **Continuous Layer Transitions**: Seamless scroll transitions between the 3D Fibonacci sphere, the agency manifesto / leadership section, and the website showcase.
- **Kinetic 3D Video Ribbon & 3-Column Responsive Grid**: Scrubbable 3D path unrolling into a responsive 3-in-a-row grid of portfolio websites.
- **Optimized WebM Video Architecture**: High-efficiency WebM (VP9) muted video loops for instant loading, smooth 60fps playback, and lightweight bandwidth.
- **Interactive Cursor Overview Badge**: Dynamic hover badge matching the sphere overview styling, with instant full-screen project enlargement modal.
